# Robot Wash Project

Комплексный анализ, прогнозирование и оптимизация финансовых показателей компании на основе методов машинного обучения.

## Описание проекта

Проект посвящён применению методов машинного обучения и интеллектуального анализа данных для прогнозирования и оптимизации финансовых показателей предприятия, занимающегося импортом из Китая и продажей автомоечных роботов на территории России.

Компания закупает роботизированные автомоечные комплексы (**Leisuwash 360**, **Leisuwash 360 Plus**), запчасти и комплектующие у китайского поставщика Leisuwash China, проходит таможенное оформление (пошлина 8%, НДС при импорте: 18% в 2015–2018, 20% в 2019–2025, 22% с 2026 года), а затем реализует оборудование российским юридическим лицам, оказывает услуги монтажа, сервисного обслуживания и продажи запчастей.

**Период данных:** 2015-01 — 2026-10  
**Объём датасета:** ~7 800 транзакций (≈7 600 чистых + 100–200 «грязных» строк)  
**Ключевые показатели:** выручка 12.4 млрд руб., прибыль 2.4 млрд руб., рентабельность 19.6%

## Задачи проекта

1. Разведочный анализ данных (EDA) и очистка «грязных» данных
2. Построение признаков (Feature Engineering)
3. Прогнозирование выручки и прибыли (регрессия, временные ряды)
4. Классификация транзакций (доход/расход, статья дохода)
5. Кластеризация клиентов и транзакций
6. Обнаружение аномалий в финансовых операциях
7. Оптимизация закупочной и сбытовой деятельности
8. Понижение размерности и визуализация (PCA, t-SNE, LDA, SVD)
9. Поиск ассоциативных правил (Apriori, FP-Growth)
10. Ансамблевые методы и стекинг (Voting, Bagging, Stacking)
11. Нейронная сеть (MLP) для сравнения с классическими моделями
12. Анализ текстовых примечаний средствами NLP
13. Байесовская оптимизация гиперпараметров (Optuna)
14. Итоговый отчёт с выводами и рекомендациями

## Содержимое папки src/

|------|-----------|
| `generate_dataset.py` | Генерация расширенного датасета (~7 800 строк) |

| `02_features.py` | Создание признаков (транзакции + помесячная агрегация) |

| `06_anomaly.py` | Обнаружение аномалий (Isolation Forest, One-Class SVM, LOF) |
| `07_timeseries.py` | Временные ряды: ARIMA, SARIMA, Prophet, LSTM |
| `08_optimization.py` | Оптимизация (linprog, SLSQP, differential_evolution) |
| `09_dimreduction.py` | Понижение размерности (PCA, t-SNE, LDA, SVD) |
| `10_association_rules.py` | Ассоциативные правила (Apriori, FP-Growth) |
| `11_stacking.py` | Ансамбли и стекинг моделей (Voting, Bagging, Stacking) |
| `12_neural_net.py` | Нейронная сеть MLP для табличных данных |
| `13_nlp_notes.py` | Анализ текстовых примечаний (TF-IDF, LDA, WordCloud) |
| `14_optuna_tuning.py` | Байесовская оптимизация гиперпараметров (Optuna) |

## Ключевые результаты

| Этап | Результат |
|------|-----------|
| **01 EDA** | 7 790 → 7 685 строк, рентабельность 19.64% |
| **03 Регрессия** | R² > 0.80 (XGBoost, LightGBM, CatBoost) |
| **04 Классификация** | F1 > 0.85 (бинарная и мультиклассовая) |
| **06 Аномалии** | ~5% согласованных аномалий |
| **07 Временные ряды** | LSTM: MAPE = 9.9% для выручки |
| **08 Оптимизация** | Потенциал роста прибыли +0.9 млрд руб. |
| **09 DimReduction** | PCA: 10 компонент = 98.5% дисперсии |
| **11 Стекинг** | R² = 0.87 — лучший результат |
| **14 Optuna** | XGBoost: R² = 0.85 после тюнинга |
