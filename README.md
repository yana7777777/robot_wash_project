# Robot Wash Project

Комплексный анализ и прогнозирование финансовых показателей компании
на основе методов машинного обучения.

## Описание проекта

Проект посвящён применению методов машинного обучения и интеллектуального
анализа данных для прогнозирования и оптимизации финансовых показателей
предприятия, занимающегося импортом и продажей автомоечных роботов.

В рамках проекта решаются задачи:
- разведочный анализ данных (EDA);
- прогнозирование выручки и прибыли (регрессия, временные ряды);
- классификация сделок (убыточные/прибыльные, тип продукта);
- кластеризация клиентов и транзакций;
- обнаружение аномалий в финансовых операциях;
- оптимизация закупочной и сбытовой деятельности.

## Структура проекта

- `data/` — исходные данные (CSV)
- `notebooks/` — Jupyter-ноутбуки (EDA, эксперименты)
- `src/` — исходный код (скрипты обработки, обучения моделей)
- `models/` — сохранённые обученные модели
- `reports/` — отчёты и графики
- `images/` — изображения для диплома

## Установка и запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/yana7777777/robot_wash_project
cd robot_wash_project

# 2. Создать виртуальное окружение
python -m venv venv

# 3. Активировать окружение
# Windows (Git Bash):
source venv/Scripts/activate
# macOS / Linux:
source venv/bin/activate

# 4. Установить зависимости
pip install -r requirements.txt

# 5. Сгенерировать датасет
python src/generate_dataset.py

# 6. Запустить Jupyter
jupyter notebook
