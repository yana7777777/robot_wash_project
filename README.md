# Robot Wash Project

Комплексный анализ, прогнозирование и оптимизация финансовых показателей
компании на основе методов машинного обучения.

## Описание проекта

Проект посвящён применению методов машинного обучения и интеллектуального
анализа данных для прогнозирования и оптимизации финансовых показателей
предприятия, занимающегося импортом из Китая и продажей автомоечных роботов
на территории России.

Компания закупает роботизированные автомоечные комплексы (Leisuwash 360,
Leisuwash 360 Plus), запчасти и комплектующие у китайского поставщика
Leisuwash China, проходит таможенное оформление (пошлина 8%, НДС при импорте
на таможне: 20% до 2026 года, 22% с 1 января 2026 года), а затем реализует
оборудование российским юридическим лицам, оказывает услуги монтажа,
сервисного обслуживания и продажи запчастей.

## Задачи проекта

- разведочный анализ данных (EDA) и очистка «грязных» данных;
- построение признаков (feature engineering);
- прогнозирование выручки и прибыли (регрессия, временные ряды);
- классификация сделок (убыточные/прибыльные, тип продукта);
- кластеризация клиентов и транзакций;
- обнаружение аномалий в финансовых операциях;
- оптимизация закупочной и сбытовой деятельности:
  определение оптимального времени, объёма и цены закупок и продаж;
- понижение размерности и визуализация данных (PCA, t-SNE, UMAP);
- поиск ассоциативных правил (Apriori, FP-Growth);
- ансамблевые методы и стекинг (Voting, Bagging, Stacking);
- нейронная сеть (MLP) для сравнения с классическими моделями;
- анализ текстовых примечаний средствами NLP;
- байесовская оптимизация гиперпараметров (Optuna).

## Структура проекта

- `data/` — исходные, очищенные и обогащённые данные (CSV)
- `src/` — исходный код: EDA, feature engineering, модели, оптимизация
- `models/` — сохранённые обученные модели (.pkl)
- `reports/` — отчёты с метриками и результатами анализа
- `images/` — графики и диаграммы для дипломной работы
- `docs/` — текст дипломной работы

## Содержимое папки src/

- `generate_dataset.py` — генерация расширенного датасета (350 строк)
- `01_eda.py` — разведочный анализ данных и проверка качества
- `02_features.py` — создание признаков (транзакции и помесячная агрегация)
- `03_regression.py` — регрессия: прогноз прибыли и выручки
- `04_classification.py` — классификация сделок и типов продуктов
- `05_clustering.py` — кластеризация клиентов и транзакций
- `06_anomaly.py` — обнаружение аномалий в финансовых операциях
- `07_timeseries.py` — временные ряды: ARIMA, Prophet, LSTM
- `08_optimization.py` — оптимизация закупок и продаж
- `09_dimreduction.py` — понижение размерности (PCA, t-SNE, UMAP)
- `10_association_rules.py` — ассоциативные правила (Apriori, FP-Growth)
- `11_stacking.py` — ансамбли и стекинг моделей
- `12_neural_net.py` — нейронная сеть MLP для табличных данных
- `13_nlp_notes.py` — анализ текстовых примечаний
- `14_optuna_tuning.py` — байесовская оптимизация гиперпараметров

## Установка и запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/yana7777777/robot_wash_project
cd robot_wash_project

# 2. Создать виртуальное окружение
python -m venv venv

# 3. Активировать окружение
# Windows (Git Bash):
source venv/Scripts/activate
# macOS / Linux:
source venv/bin/activate

# 4. Установить зависимости
pip install -r requirements.txt

# 5. Сгенерировать датасет
python src/generate_dataset.py

# 6. Запустить этапы анализа по порядку
python src/01_eda.py
python src/02_features.py
python src/03_regression.py
# и так далее
