3.1. СОЗДАНО 21 НОВЫЙ ПРИЗНАК:

  ФИНАНСОВЫЕ:
    • profit          = income − expense (по строке)
    • total_amount    = income + expense
    • unit_price      = income / quantity
    • unit_cost       = expense / quantity (для импорта)

  ФЛАГИ ТИПА ОПЕРАЦИИ:
    • is_income, is_expense, is_import,
    • is_robot_sale, is_service, is_customs, is_logistics

  ВРЕМЕННЫЕ:
    • day_of_week, day_of_month, week_of_year,
    • season (Зима/Весна/Лето/Осень), quarter_num, days_since_start

  ДОЛИ ЗАТРАТ:
    • customs_share   = (пошлина + НДС + сбор) / expense
    • vat_share       = НДС / expense
    • logistics_share = доставка / expense
    • bank_share      = комиссия / expense

3.2. ПОМЕСЯЧНАЯ АГРЕГАЦИЯ:

3.3. АНАЛИЗ:
  Feature Engineering позволил:
  • Создать 21 признак (из 25 → 46 колонок).
  • Учесть сезонность через season и quarter_num.
  • Добавить лаги для временных рядов (важно для этапов 03, 07).
  • Выделить доли затрат для анализа структуры себестоимости.

3.4. ВЫВОД:
